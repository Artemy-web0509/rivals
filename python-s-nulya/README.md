# Python с нуля

Интерактивный тренажёр для изучения Python с нуля прямо в браузере.

## Как открыть

**Вариант 1. GitHub Pages (онлайн)**
После публикации будет доступен по ссылке вида: `https://artemy-web0509.github.io/rivals/python-s-nulya/`

**Вариант 2. Локально**
1. Скачай или клонируй репозиторий
2. Открой `python-s-nulya/index.html` в браузере

## Особенности

- Уроки на русском языке
- Редактор кода + консоль прямо на сайте
- Python запускается в браузере через [Pyodide](https://pyodide.org/)
- Прогресс сохраняется в `localStorage`
- 7 уроков с нуля + мини-проект "Угадай число"

## Структура

- `index.html` — главная страница
- `css/style.css` — стили
- `js/lessons.js` — все уроки
- `js/app.js` — логика сайта
- `js/editor.js` — редактор кода
- `js/pyodide-runner.js` — запуск Python

Сделано для абсолютного нуля. Читай, пиши код, запускай, практикуйся.
